# Hunt Engine v3.13.0 — Controlled Runtime Expansion + AI Pentest Reasoning Foundation

v3.13.0 introduces the first evidence-driven AI Pentest Operator hunting foundation. This release is not full exploitation and does not yet provide bug-class-specific validation packs; those are planned for later milestones. The goal of this version is to make the Operator reason over target evidence, choose multiple high-value candidates, execute controlled low-risk baseline probes, analyze runtime results, learn from those results, and avoid repeating low-value tests.

## Highlights

- Added a small multi-candidate controlled baseline hunting loop for high-impact bug-hunting intents.
- Replaced single-candidate high-value probing with a bounded candidate loop.
- Added per-step `hunting_session` output in chat `output_json`.
- Improved chat readability for operator-visible steps and runtime analysis.
- Added Probe Result Analyzer v1 for controlled runtime evidence.
- Persisted analyzer learning into target RAG memory.
- Added memory-aware avoid-retesting so blocked, challenged, TLS-failed, timeout, forbidden, and rate-limited candidates are skipped in later loops.
- Added official smoke coverage in `scripts/smoke_operator_hunting_loop_v313.sh`.
- Added fast backend reload support for development without rebuilding Docker images on every backend code change.

## Guardrails

- Low-risk baseline probes may execute through Operator Autopilot when target policy allows.
- High-risk validation remains approval-gated.
- Blocked, challenged, inconclusive, WAF/Cloudflare, 403, 429, 5xx, TLS, and timeout evidence is not promoted as vulnerability proof.
- Runtime analysis is used to guide the next controlled step, not to overclaim findings.

## Current limitations

- v3.13.0 is a controlled hunting foundation, not full exploitation.
- Bug-class-specific validation for XSS, CRLF, open redirect, path traversal, cache issues, auth/IDOR, SQLi, SSRF, RCE, and other classes is planned for later releases.
- Authenticated context and two-account access-control testing are not part of this milestone.
- Finding promotion from controlled validation evidence remains a later workflow.
