# Hunt Engine v3.15.1 Release Notes

v3.15.1 closes the v3.15 bug-class validation runtime gap by adding controlled, evidence-producing Level 2 validation runtimes for the built-in bug-class skills introduced in v3.15.

## Added

- v3.15.1 bug-class validation skill registry entries:
  - `xss_reflection_context`
  - `dom_xss`
  - `crlf_header_injection`
  - `cache_poisoning_deception`
  - `open_redirect_chain`
  - `path_traversal_file_read_baseline`
  - `cors_clickjacking_csrf`

- Dispatcher execution support for all v3.15.1 bug-class validation skills.

- Controlled XSS reflection context validation:
  - inert marker GET probes
  - reflection detection
  - rough reflection context classification
  - Content-Type and CSP evidence capture
  - blocked/inconclusive handling for 403/429/5xx

- Controlled open redirect chain validation:
  - inert marker URL probe
  - redirects are not followed
  - Location header capture
  - same-origin/external/protocol-relative/relative classification

- Controlled CRLF/header injection validation:
  - encoded marker probing only
  - response header/body marker evidence
  - no raw CRLF payload execution

- Controlled cache poisoning/deception validation:
  - cache-buster marker
  - two GET comparison
  - cache-relevant header capture
  - no cache poisoning payload execution

- Controlled CORS/clickjacking/CSRF baseline validation:
  - GET and OPTIONS header evidence
  - ACAO/ACAC/Vary Origin capture
  - X-Frame-Options and CSP frame-ancestors capture
  - Set-Cookie flag baseline
  - no state-changing CSRF execution

- DOM XSS source/sink evidence runtime:
  - JavaScript/DOM candidate collection
  - static source/sink signal extraction
  - no browser execution
  - no payload execution

- Path traversal/file-read baseline validation:
  - inert path marker variants
  - response variation/error signal detection
  - no sensitive file-read proof
  - no destructive or state-changing request

- Official smoke script:
  - `scripts/smoke_operator_bug_class_validation_v3151.sh`

## Controlled execution boundaries

v3.15.1 implements controlled active validation evidence. It does not implement browser proof, destructive payloads, state-changing CSRF execution, raw CRLF payload execution, cache poisoning payloads, external redirect following, sensitive file-read proof, SSRF/OOB proof, SQLi proof, RCE proof, or arbitrary shell/tool execution.

Those capabilities remain future authorized execution milestones under explicit scope, authorization, policy, budget, audit, and stop-condition controls.

## Validation

The v3.15.1 smoke verifies that all built-in bug-class validation runtimes execute and that no v3.15.1 validation slug remains in `not_implemented`.
